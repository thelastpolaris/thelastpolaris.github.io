# Портфолио Артема Федоскина

Это одностраничный сайт-портфолио для Артема Федоскина, Product Manager из Астаны. Проект создан с использованием React, TypeScript и стилизован с помощью Tailwind CSS.

## Стек технологий

-   **React** - Библиотека для создания пользовательских интерфейсов.
-   **TypeScript** - Типизированный JavaScript для повышения надежности кода.
-   **Tailwind CSS** - Утилитарный CSS-фреймворк для быстрой стилизации.
-   **Vite** - Современный и быстрый сборщик для веб-приложений.

## Локальная разработка

Для запуска проекта на вашем компьютере выполните следующие шаги:

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <URL вашего репозитория>
    cd <название папки>
    ```

2.  **Установите зависимости:**
    Убедитесь, что у вас установлен [Node.js](https://nodejs.org/). Затем выполните команду:
    ```bash
    npm install
    ```

3.  **Запустите сервер для разработки:**
    ```bash
    npm run dev
    ```
    Эта команда запустит локальный сервер. Откройте браузер и перейдите по адресу, указанному в терминале (обычно `http://localhost:5173`).

## Автоматическое развертывание на GitHub Pages

Этот проект настроен для автоматического развертывания на GitHub Pages при каждом коммите в ветку `main`.

**Что нужно сделать:**

1.  **Создайте репозиторий на GitHub** с названием `thelastpolaris.github.io`. Это важно для того, чтобы сайт был доступен по адресу `https://thelastpolaris.github.io/`.
2.  **Загрузите файлы проекта** в этот репозиторий.
3.  **Дождитесь выполнения Action.** После вашего первого `git push` в ветку `main`, автоматически запустится GitHub Action, который соберет проект и развернет его. Вы можете отслеживать прогресс во вкладке "Actions" вашего репозитория.
4.  **Настройте GitHub Pages.** После того как Action успешно завершится (это может занять несколько минут), перейдите в настройки вашего репозитория (`Settings` -> `Pages`). В разделе "Build and deployment" выберите источником (`Source`) ветку `gh-pages` и папку `/ (root)`. Сохраните изменения.

Ваш сайт будет доступен через несколько минут по адресу `https://thelastpolaris.github.io/`. Все последующие коммиты в `main` будут автоматически обновлять сайт.
